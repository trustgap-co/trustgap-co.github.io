# Website images

Drop these files in this folder with **exactly** these names. Until a file is here, the page shows a
labelled placeholder in its place. All are **PNG**, landscape 4:3 at 1200×900 unless noted.

PNG photos are large straight from a camera or phone (often 2–3 MB). Before uploading, shrink each one
at **tinypng.com** (free, keeps it PNG) and aim for under ~400 KB, so pages stay fast on mobile data.
Photos only load when they scroll into view, but smaller is still better.
